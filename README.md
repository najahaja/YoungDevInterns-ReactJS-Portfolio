## Run Locally

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the app in your browser at:

```bash
http://localhost:5173
```

## Build for Production

```bash
npm run build
```

## Deployment

```bash
npm run deploy
```
